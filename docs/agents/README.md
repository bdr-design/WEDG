# How the agents are directed

The owner's rule of 13 Nov 2026 (CLAUDE.md): agents build and fix, each with its own reviewer agent started
alongside it; the session directs, re-measures and reviews. These are the working papers of that day, kept here so
they survive the work machine (they lived in its scratch folder, which a restart can clear).

- `GUIDE.md`: what every agent reads first (the two roles, the environment, the checks, the disk).
- `T*_*.md`: each task's brief. Paths beginning `$SC` are the work machine's scratch folder: harnesses and review
  notes named there are not in the repository.
- `T3_T4_owner_decisions.md`: the owner's decisions of 13 Nov on festivals, cheating, debt and the merchant's
  account, the sale of a treated camel, and the المزاين design, in the words of the options he chose (decisions 1
  to 18). The GDD (sections 7, 7.1, 8) carries them as rules; this file is the record of how each was put to him.
- `T4_round3_findings.md`: a reviewer's findings kept for a later round.

Unmerged work is backed up on side branches `wip/<task>` (the owner's permission, 13 Nov).
